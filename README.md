# InnovativeWirelessPlatformsForIoT
This study investigates deep learning techniques employed to estimate the Evapotranspiration, the process by which water is transferred from the soil and plants to the atmosphere through evaporation or transpiration. Performing accurate estimations of evapotranspiration is crucial in agriculure, where it can help to optimize irrigation and reduce water waste. The research reviews 160 papers according to prediction algorithms, performance metrics, and details about datasets and study areas. Moreover, a personal implementation of a Long Short-Term Memory (LSTM) model was developed and tested to perform predictions of the actual evapotranspiration in the Piedmont region in Italy.
